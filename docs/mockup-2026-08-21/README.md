Von Lukas geliefertes Design-Mockup für MusicMaster. Soll als visuelle Referenz für das Dashboard
(LUH-110) und generell das Farbschema/Layout der App übernommen werden.

- Sidebar-Navigation: Dashboard, Probenplan, Mitglieder, Notenarchiv (+ neu: Instrumente, siehe LUH-121)
- Header: Begrüßung mit Nutzername, "Exportieren" + "Termin anlegen"-Buttons
- Kennzahlen-Kacheln: Aktive Mitglieder, Ø Anwesenheit, Offene Beiträge, Tage bis Jahreskonzert
- "Nächste Gesamtprobe"-Widget mit Zu-/Absagen-Zähler
- "Anstehende Termine"-Liste
- "Besetzung nach Register"-Balkendiagramm (Soll/Ist pro Instrumentengruppe)
- "Zu erledigen"-Checkliste
- Farbschema: warmes Creme/Beige als Hintergrund, dunkles Grün als Akzent, Orange für Primär-Buttons, Oliv/Dunkelrot für Chart-Balken (Soll erfüllt/nicht erfüllt)
